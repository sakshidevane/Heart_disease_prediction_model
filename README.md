# Heart Disease Prediction Project ❤️📊

---

## 📌 Overview

This repository contains my **Heart Disease Prediction Project** developed using Python and Machine Learning techniques.

The objective of this project is to predict whether a person is likely to have heart disease based on medical attributes such as age, sex, chest pain type, cholesterol level, blood pressure, and other health-related features.

This project follows a complete **Machine Learning workflow**, including data preprocessing, exploratory data analysis (EDA), feature engineering, model building, evaluation, and prediction.

---

## 🎯 Project Objective

* Analyze medical dataset related to heart disease
* Understand relationships between health parameters and disease occurrence
* Build a classification model to predict heart disease
* Improve problem-solving and analytical skills
* Gain hands-on experience in real-world ML workflows
